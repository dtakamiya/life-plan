# ペルソナ操作レビュー: 低収入・単身

実施日: 2026-09-25 / 対象: `main`（956da5a）をローカル `npm run dev` で操作

## ペルソナ

- 35歳（1991年生）単身、非正規雇用、年収（税込）240万円
- 基礎生活費 150万円/年、貯蓄 30万円、退職金なし
- 年金は国民年金のみ想定（年額 80万円）、NISA 積立なし

## 操作の流れ

1. 「初期値に戻す」→ 年収・年金・退職一時金・生活費・資産・積立を書き換え
2. 配偶者を「なし」に切替
3. 既定で入っている 子1人・住宅ローン3,000万円・住宅購入イベント（-500万円）を1件ずつ削除
4. 結果（サマリ・グラフ・年次明細）と「計算の前提」を確認

結果: 64歳まで毎年約44〜55万円の黒字 → 65歳以降は毎年約120〜190万円の赤字 → **84歳（2075年）で資産がなくなる**、95歳時点の純資産は -2,417万円。

## 改善点

### 計算・前提（優先度高）

| # | 内容 | 根拠 / 影響 |
|---|---|---|
| 1 | ✅ 対応済み: **年収上昇率 1%/年が画面から見えず、変更もできない** | `defaults.ts` の `incomeGrowthRate: 0.01` が固定。240万円の年収が64歳には320万円まで自動で増える。昇給のない非正規では現役期の貯蓄を多く見積もり、資産がなくなる年を遅く見せてしまう。本人の入力欄に「年収上昇率」を追加し、「計算の前提」にも載せる。 |
| 2 | ✅ 対応済み: **マイナス残高にも運用利回り（3%）の複利が掛かる** | `engine.ts:187` の `taxableGain = taxableBase * returnRate` は、`taxableBase < 0` でも計算される。そのため資産がなくなった後の赤字が、年3%の「借入利息」で膨らむ（2075→2076年で約2.8万円の上乗せ）。マイナス時は利回り0にするか、借入金利を別に設けるべき。 |
| 3 | 年金を65歳から一定額で固定、生活費は物価上昇率で増える | 「年金 80万円」は95歳まで変わらず、生活費だけが毎年1%増える。低収入層は年金の比重が大きいので、収支の差が広がりやすい。年金にもスライド率（例: 物価連動 − マクロ経済スライド）を設けたい。 |
| 4 | ✅ 対応済み: 年金の既定値が厚生年金加入を前提にしている | 概算方式は「基礎年金78万円 + 年収×12%」。非正規・自営で国民年金だけの人は、既定値を自分で下げる必要があり、それに気づけない。「国民年金のみ / 厚生年金あり」の切替を設ける。 |
| 5 | 高齢期（年金収入）の社会保険料が0円 | 「年金収入には掛けない」ため、国保・介護保険料（低所得でも年数万円）が入らない。 |
| 6 | 低所得向けの税制が反映されていない | 基礎控除48万円・住民税一律10%の簡易計算。2025年改正の基礎控除の引き上げ（低所得ほど大きい）や住民税非課税の判定がないため、低所得層では税負担のずれが相対的に大きい。少なくとも前提の注記で触れる。 |
| 7 | 余剰資金が全額3%で運用される前提 | 課税口座は「預金含む」とあるが、全額に運用利回りが掛かる。生活防衛資金をためるだけの層には過大。預金と運用を分けるか、利回りの目安（預金なら0〜0.3%）を案内する。 |

### 入力・操作性

| # | 内容 | 根拠 / 影響 |
|---|---|---|
| 8 | 単身・子なしにするまでの操作が多い | 「初期値に戻す」は子1人＋ローン＋住宅購入が入った世帯になる。配偶者を外しても子・ローン・イベントは残り、3件それぞれに確認ダイアログが出る（計6クリック）。「単身・賃貸」「夫婦・子あり」などのプリセットを選べるようにする。 |
| 9 | ✅ 対応済み: 配偶者の切替ボタンの意味が分かりにくい | 「配偶者なし」の状態でも、右上のボタンには「配偶者あり」と出ている（押すと「あり」になるボタン）。ボタンが操作を示すのか、今の状態を示すのか分からない。ラジオやセグメント型の「あり / なし」にする。 |
| 10 | ✅ 対応済み: 家賃の入力場所が分かりにくい | 生活費に家賃を含めるのか、「継続支出」に入れるのか、案内がない。単身の賃貸住まいでは家賃が支出の大部分を占める。生活費欄の補足に「家賃は継続支出へ」などと書く。 |
| 11 | ✅ 対応済み: 以前のデータに年収 50,000万円・借入額0のローンが残っていた | 前回の操作で入った値だと思われるが、桁違いの年収にも警告が出ない。極端な値（例: 年収1億円超）には「桁は合っていますか？」と注意を出す。 |

### 結果の見せ方

| # | 内容 | 根拠 / 影響 |
|---|---|---|
| 12 | 資産がなくなると分かっても、次に何をすればよいか示されない | 「83歳まで資産が持ちます」のあと、-2,417万円のグラフが続くだけ。「生活費をあと月◯万円減らす」「◯歳まで働く」「年金を◯歳まで繰り下げる」で資産がなくならなくなる、といった逆算の提案があると行動につながる。 |
| 13 | マイナス側に大きく伸びるグラフが不安を強める | 資産がなくなった後も -2,400万円まで線が伸びる。低収入の利用者には必要以上に悲観的に見える。なくなった後は網掛けだけにする、または「不足額の累計」として別に示す。 |
| 14 | 公的な支えについての説明がない | 資産がなくなった後の生活保護や高齢者向けの支援制度には触れていない。シミュレーションの範囲外であることと、相談窓口への一文を添えるとよい。 |
| 15 | ✅ 対応済み: 最小純資産と最終純資産が同じ値で重複して表示される | 資産がずっと減り続けるケースでは、2枚のカードの値が同じになり情報が増えない。同じ値のときは1枚にまとめるなどしたい。 |
| 16 | ゲームモードも高収入の世帯を前提にしている可能性 | 今回は未検証。選択肢（住宅購入・投資など）が低収入の人にとって現実的か、別途確認が必要。 |

## 対応状況

✅ の項目（#1, #2, #4, #9, #10, #11, #15）は `fix/low-income-persona` で対応した。残りは別PRで扱う。

2. #1（年収上昇率を見えるようにし、変えられるようにする）、#4（年金種別）: 低収入層で結果が大きく変わる
3. #8・#9（プリセット、切替ボタン）: 入力の手間とつまずきを減らす
4. #12（逆算の提案）: 低収入層にとって一番価値がある追加機能
