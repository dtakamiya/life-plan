# ペルソナ操作レビュー: 子育て共働き世帯

実施日: 2026-09-25 / 対象: `main`（ebe0e7e）をローカル `npm run dev` で操作

## ペルソナ

- 本人35歳（1991年生）年収500万円、配偶者 年収300万円の共働き
- 子1（3歳）、第2子を2028年に出産予定
- 2030年まで賃貸（家賃 年144万円）→ 2031年に住宅購入（頭金500万円＋ローン4,500万円・35年・1%）

## 操作の流れ

1. 「初期値に戻す」（夫婦＋子1人＋ローン3,000万円＋頭金の既定値）
2. ローン借入額を4,500万円に変更
3. 子を追加して生年を2028にする
4. 継続支出に「家賃」2026〜2030年・年144万円を追加
5. サマリ・グラフ・年次明細を確認し、390px幅でも表示を確認

結果（修正前）: **2031年（40歳）に資産が尽きる**、95歳時点の純資産は -1億2,563万円。改善の目安は「生活費を月92,000円減らす」の1案だけ。

修正後（#1 対応）: 同じ操作で資産は尽きず、95歳時点の純資産は 4,785万円。

## 改善点

### 計算・前提（優先度高）

| # | 内容 | 根拠 / 影響 |
|---|---|---|
| 1 | ✅ 対応済み: **子の養育費を二重に計上している** | 子を追加すると、基礎生活費が自動で +60万円（360万→420万円）になる（`householdDefaults.ts:35` `perChildLivingExpense`）。さらに計算側でも、子1人あたり 60万円/年を22歳まで加算している（`education.ts:13` `BASE_CHILD_ANNUAL_COST`）。基礎生活費の加算分は、**子が生まれる前（2026年）から本人95歳まで**ずっと残る。第2子1人で生涯の支出が数千万円多くなり、資産が尽きる年が早まる主な原因になっている。 |
| 2 | **住宅を資産に計上していない** | 住宅購入の年に、純資産が約 +316万円から -4,671万円へ落ちる（ローン残高を差し引くだけで、不動産の価値を資産に加えていない）。住宅を買うだけで「最小純資産 -1,726万円」（既定値の時点）と表示され、持ち家世帯は不安になる。住宅の評価額（減価を含めて）を資産に加えるか、少なくとも「純資産に不動産は含めない」と明記する。 |
| 3 | 共働きの出来事を表現できない | 産休・育休・時短勤務による**一定期間の収入減**を入れる手段がない（年収は1つの値と上昇率だけ。ライフイベントはその年1回の収支のみ）。 |
| 4 | 子育て世帯向けの給付・控除がない | 児童手当、住宅ローン控除（最大で年数十万円×13年）が収入に入らない。どちらも子育て世帯の収支を大きく左右する。 |
| 5 | ✅ 対応済み: 持ち家の維持費を案内していない | 固定資産税・修繕積立金の入力場所や案内がない（家賃は案内済み）。「継続支出に入れる」旨を住宅購入・ローン欄に書き添える。 |

### 入力・操作性

| # | 内容 | 根拠 / 影響 |
|---|---|---|
| 6 | ✅ 対応済み: 子を追加すると、基礎生活費が知らせなく書き換わる | 画面上の値が 360万→420万円 に変わるが、通知も説明もない。#1 を直すなら、この自動加算自体をなくす。 |
| 7 | ✅ 対応済み: 生まれる前の子が分かりにくい | 子1には「子1（3歳）」と出るが、2028年生まれの子2は「子2」とだけ出る。「2028年生まれ予定」などと表示する。 |
| 8 | ✅ 対応済み: 住宅購入イベントとローンが連動しない | ローンの返済開始年と、頭金イベントの年を別々に直す必要がある。購入年を変えたときにずれやすい。 |
| 9 | ✅ 対応済み: 改善の目安が1案だけ | 生活費の削減しか出ず、「住宅予算を下げる」「購入時期を遅らせる」「繰上げ返済」など、子育て世帯が実際に選べる案がない。 |
| 10 | ✅ 対応済み: 世帯年収800万円なのに生活困窮の相談窓口が案内される | 一時的に資産がマイナスになるだけのプランにも「生活保護」「生活困窮者自立相談支援窓口」の文言が出る。資産が尽きる時期や年齢によって文言を出し分ける。 |
