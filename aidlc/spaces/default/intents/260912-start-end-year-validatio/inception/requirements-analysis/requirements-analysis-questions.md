## Consolidated Summary Confirmation

- 修正方式は「自動補正」を採用する。バリデーションエラー表示ではなく、システム側で値を自動的に補正する。
- 有効な期間の最低要件は「2年以上」とする（`endYear >= startYear + 1`）。開始年 = 終了年（1年間のみ）は無効とし、補正対象に含める。
- 補正ロジックは「開始年基準」とする。開始年 > 終了年、または期間が2年未満の場合、`endYear = startYear + 1` に自動設定する。
- 補正を行った場合、終了年の入力欄の直下に、既存の `NumberField` の `error` prop と同じスタイル（aria-invalid連携）で「終了年を自動調整しました」等の注意文言を表示する。
- 今回の修正スコープには「人生ゲーム」モードも含める。フォーム/ストア層でバリデーション・補正を行うことで、メインシミュレーターと人生ゲームの両方に効かせる前提とする。
- 結果が空の場合の一般的なハンドリング（`Summary`、`ResultTable`、各チャート）も改修範囲に含める。「表示できる結果がありません」等の汎用メッセージを共通で表示する。
- 補正後の値は表示上の警告に留めず、`usePlanStore` 内部の `endYear` 自体を書き換える。以降のシミュレーションは補正後の値で実行する（レビュー起因の追加確認）。
- `localStorage` から既存データを復元する際に、既に無効な期間が保存されていた場合も、フォーム入力時と同じロジックで自動補正・通知を行う（レビュー起因の追加確認）。
