# ビジネス概要（life-plan）

## ドメイン

`life-plan` は、世帯（本人・配偶者・子ども等）の資産形成をシミュレーションする
クライアントサイド Web アプリケーション。ユーザーが世帯構成・収入・支出・資産・
ローン・イベント等を入力すると、指定した開始年〜終了年の各年について収支・資産
残高・純資産を計算し、表とグラフで提示する「ライフプラン・シミュレーター」を
中核機能とする。

これに加えて、同じシミュレーション入力を使いながら年ごとの出来事をロールプレイ
風の「ステージ」として演出する「人生ゲーム」モード（`src/app/game/`）を提供する。
両モードは同一のドメイン入力（`PlanInput` の `startYear` / `endYear` を含む）を
共有する。

## 目的

- 世帯が将来の資産推移を可視化し、住宅ローン・教育費・年金・社会保険・税制等を
  織り込んだ長期的な家計計画を検討できるようにすること。
- 入力はブラウザの `localStorage` にのみ保存され、外部サーバーへの送信は行わない
  （プライバシーを保った個人向けツールという位置づけ）。

## 主要機能

- 世帯情報・収入・支出・資産・ローン・イベントの入力フォーム
  （`src/components/forms/`）。
- シミュレーション実行エンジン（`src/lib/simulation/engine.ts` の
  `runSimulation`）— 詳細は `architecture.md` および `code-structure.md` を参照。
- 結果表示（`ResultTable`、各種チャート）。
- 「人生ゲーム」モード（`src/lib/game/`, `src/app/game/`）。
- 入力状態の永続化・復元（Zustand `persist` + zod `safeParse`、詳細は
  `technology-stack.md` を参照）。

## 今回のインテントとの関連

インテント `start-end-year-validatio`（scope: bugfix）は GitHub issue #14
「シミュレーション期間の開始年が終了年より後の場合に、エラー表示なく結果が無言で
空白になる」に対応する。この不具合の技術的な原因分析は
`code-quality-assessment.md` の「Technical Debt Signals」に一本化して記録する
（本ファイルでは重複記載しない）。

## 利用者像

- 単一の世帯・個人が自身のPCで手元ビルドして使うことを想定（`team.md` の
  Deployment 方針: ローカル環境または自宅サーバーで運用、外部ホスティングなし）。
- 複数ユーザー・マルチテナントの想定はなく、認証機構も存在しない。
